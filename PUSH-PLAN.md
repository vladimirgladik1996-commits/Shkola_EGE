## Гипотезы: что подтвердилось

1. **Мышление на английском.** Верно: «Отвечай по-русски» просило ответ, но язык
   размышлений не задавался нигде; модель k2.x/k3 по умолчанию мыслит по-английски даже на
   русском вопросе, языкового параметра reasoning у Moonshot API нет. Видимое пользователю
   мышление — ровно четыре промта (см. Пуш 2): мини-апп, бот (deep), «Спросить у Вишенки»,
   прелоадер ИИ-проверки (`_collect(msg_crit, thinking=True, emit=True)`).
2. **Рассуждения пропадали.** Верно: `localStorage.chHist` + вырезание шагов при
   сохранении + перезагрузка страницы при возврате = мыслей нет; сохранение шло только в
   начале и в конце запроса. Уточнение к формулировке: реплика пользователя всё же
   сохранялась в начале запроса — терялись рассуждения и недособранный ответ.
3. **Вставка в АПК.** Верно: `onLongClick` всегда `return true` (нужен для служебного меню
   «Сменить адрес»), WebView из-за этого не запускал режим выделения; поле ввода чата —
   `<textarea id="aic-in">`. Фикс живёт в Java-обёртке → без пересборки APK не доедет;
   пересборку делает CI (см. Пуш 4).
