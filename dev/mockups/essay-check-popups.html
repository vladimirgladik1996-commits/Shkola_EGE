ИИ-проверка · поп-апы перед проверкой

Появляются после «Готово», если не хватает фото. Тап по кнопкам работает: «Добавить» возвращает на съёмку с нужным чипом, «Продолжить без задания» уходит к обработке.

Как это работает

  • Только работа — «Добавить» → съёмка, активен чип «Задание». «Продолжить без задания» → обработка по тому, что есть; критерии про смысл исходного текста не оцениваются, ничего не додумывается.
  • Только задание — одна кнопка «Добавить» → съёмка, активен чип «Работа». Пропустить нельзя.
  • Строки статуса повторяют чипы камеры. Золотая точка — можно продолжить, красная — нельзя. Фото в счётчике видны сразу.
  • Фон и карточка — как у модалок раздела (.ec-mod / .ec-mc), цвета — токены кабинета, тёмная тема из макета. Тап по фону не закрывает: решение нужно принять.
  • Код для внедрения — popups-integration.md.
