# dev/mockups/ — макеты новых разделов

Дизайн до внедрения в код. Макеты лежат **вне** `bot-mini-app/`, поэтому
контракт паритета dev/prod на них не действует — это черновой материал
для dev-контура.

## Правила

- Один раздел — один самодостаточный HTML (открывается двойным кликом,
  без сборки и зависимостей, кроме Google Fonts).
- Дизайн-токены (цвета, шрифт Nunito) — как в `docs/index.html` мини-аппа,
  чтобы макет был частью того же продукта.
- Демо-данные — реалистичные и методологически верные (баллы ФИПИ сходятся,
  ошибки в тексте — настоящие типичные ошибки учеников).
- Когда раздел внедрён в код, макет остаётся здесь как справка по дизайну.

## Сейчас

- `essay-check.html` — раздел «ИИ-проверка» (сочинение ЕГЭ / эссе ОГЭ):
  старт → съёмка → обработка → превью с разбором ошибок и критериями ФИПИ.
  Полная версия 21.10.2026 (`essay-check-full.patch`): добавлены экран старта
  с двумя большими кнопками, съёмка с общим потоком камеры, голосовой виджет
  Вишенки, режим «Т/П». Фиксы чистки перенесены повторно: фрагменты текста
  в модалке ошибки (кортежи через запятую → массивы — иначе модалка показывала
  три символа), защита от повторного действия «Исправить/Удалить» (счётчик
  ошибок и TypeError), Esc закрывает модалку и голосовой лист.
- `essay-check-popups.html` — поп-апы «не хватает фото» перед проверкой:
  «Не вижу задания» (есть работа: «Добавить задание» / «Продолжить без задания»)
  и «Не вижу сочинения/эссе» (есть только задание: одна кнопка «Добавить»).
  Светлая и тёмная тема, переключатель ЕГЭ/ОГЭ.
- `popups-integration.md` — CSS, JS и хук в `ecUpload` для внедрения поп-апов в `docs/index.html`.
- `preloader.html` — макет экрана загрузки: «Загрузка», золотая шапа-прогресс,
  летящие иконки. Самодостаточный, картинка зашита base64.
- `assets/` — исходные иллюстрации Вишенки (`vishenka-start.png`,
  `vishenka-processing.png`, `vishenka-camera-button.png`). В самих макетах
  стоят оптимизированные webp-версии прямо в разметке — чтобы HTML
  открывался двойным кликом без соседних файлов; PNG здесь как источник.
- `camera-integration.md` — как устроить доступ к камере в «ИИ-проверке»
  (общий поток `camHub`, тот же путь, что «Снять камерой» в чате с ИИ).
- `voice-widget.md` — что нужно доделать на сервере для голосового виджета
  Вишенки (контекст `essay`, действия `fix_error`/`edit_ocr`).

План пушей и релиза — в корне репозитория: `PUSH-PLAN.md`.
