# dev/mockups/ — макеты новых разделов

Дизайн до внедрения в код. Макеты лежат **вне** `bot-mini-app/`, поэтому
контракт паритета dev/prod на них не действует — это черновой материал
для dev-контура.

## Правила

- Один раздел — один самодостаточный HTML (открывается двойным кликом,
  без сборки и зависимостей, кроме Google Fonts).
- Дизайн-токены (цвета, шрифт Nunito) — как в `docs/index.html` мини-аппа,
  чтобы макет был частью того же продукта.
- Демо-данные — реалистичные и методологически верные (баллы ФИПИ сходятся,
  ошибки в тексте — настоящие типичные ошибки учеников).
- Когда раздел внедрён в код, макет остаётся здесь как справка по дизайну.
