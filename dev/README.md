# DEV — тестовая версия

Здесь проверяют новые фичи перед переносом в `prod/`. Состав:

- `bot-mini-app/` — Telegram-бот + мини-апп (запуск и настройки: `bot-mini-app/DEPLOY.md`)
- `apk/` — Android-приложение «Надежда DEV» (сборка: `apk/README.md`)

Особенности dev:

- **свой бот Telegram** (второй, от @BotFather) — токен нельзя совмещать с продом;
- **своя тестовая база** `bot-mini-app/data/tutor.db` — можно смело удалять;
- `APP_ENV=dev` → пометка «DEV» в сообщениях бота и в мини-аппе;
- `LOG_LEVEL=DEBUG`, анти-сон выключен (`KEEPALIVE_SEC=0`);
- в мини-аппе без доступа к API включается демо-режим с примерными данными.

Проверили — переносим изменения в `../prod/` (файл в файл).
