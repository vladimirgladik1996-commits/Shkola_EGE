# Бот репетитора + мини-апп

## Запуск
1. Создайте бота в @BotFather, получите токен. Свой Telegram ID узнайте у @userinfobot.
2. Установите зависимости: `pip install -r requirements.txt`
3. Мини-аппу нужен публичный https-адрес. Для теста: `cloudflared tunnel --url http://localhost:8080` (или ngrok). На сервере — nginx + сертификат.
4. Запуск:

```
export BOT_TOKEN=123:abc
export OWNER_ID=111222333
export WEBAPP_URL=https://ваш-адрес
export CURRENCY=₽        # необязательно
python bot.py
```
5. Откройте бота, нажмите /start.

## Как считаются долги
У каждого ученика указана цена занятия. Баланс = все оплаты − (проведённые занятия × цена).
Занятие считается проведённым, когда его время наступило. Баланс < 0 — долг, > 0 — оплата наперёд.

Данные хранятся в файле `tutor.db` (SQLite).

## Регулярные занятия
«Сделать регулярным» ставит занятие на тот же день недели и время каждую неделю (система держит расписание на 12 недель вперёд и дозаполняет его сама).
- «Отменить это занятие» убирает только одно занятие серии.
- «Перенести» двигает только выбранное занятие.
- «Прекратить серию» удаляет это и все следующие занятия серии.
Если время в какую-то неделю уже занято другим учеником, это занятие пропускается, и об этом сообщается.

## Печать недели
В «Расписании» кнопка «🖨 Распечатать» открывает предпросмотр A4: сетка «время × 7 дней» текущей недели с именами учеников.
Кнопка «Поделиться PDF»: если телефон умеет делиться файлами напрямую, откроется меню приложений; иначе бот пришлёт PDF в чат с вами, и его можно переслать в любой мессенджер.
PDF строится на сервере (reportlab), шрифт DejaVu лежит в папке `fonts/`.

## Оплаты: лента, фильтры, редактирование
Вкладка «Оплаты» — общая статистика, фильтры «Все / Должники / Предоплата» (фильтруют и списки, и ленту), и лента поступлений: аватар, имя, дата и время, сумма. У каждой записи значок ✏️ — можно изменить сумму или удалить платёж (баланс ученика пересчитается сразу).

## Ученики: список и карточка
Вкладка «Ученики» — список с аватарами и статусом (долг/наперёд/оплачено). Тап по ученику открывает карточку: фото (нажать на карандаш, чтобы загрузить своё), редактируемое ФИО, число проведённых занятий, оплачено всего, текущий баланс, последние 5 платежей. Кнопка «Сохранить» применяет изменения имени и фото.

## Календарь: карточка дня
Тап по дню в сетке открывает карточку с занятиями этого дня (время и ученик) и кнопкой «+ Добавить занятие» на эту дату. Тап по занятию — карточка переноса/отмены/регулярности, как раньше.

## Печатная форма расписания
Лист A4 альбомной ориентации, рассчитан на чёрно-белую печать: у пустых часов — нейтральная серая заливка строки (для навигации по сетке), у занятых — белая ячейка с жирной чёрной полосой слева. Ничего не завязано на цвет конкретного ученика, поэтому ничего не «сливается» при печати без цвета. Имя ученика — крупным жирным шрифтом, регулярные занятия помечены подписью «повтор». Дни недели — полными названиями (Понедельник…Воскресенье) с датой под названием.

## Точное время занятия
Кнопки-часы (08:00…20:00) остаются быстрым способом выбрать время, но теперь есть и второй вариант — точное время с любыми минутами (например 8:25 или 14:40):
- В боте: на шаге выбора времени внизу кнопка «🕐 Своё время» — бот попросит ввести время текстом (ЧЧ:ММ).
- В мини-аппе: под выпадающим списком часов — ссылка «Указать точное время», переключает поле на нативный выбор часов/минут.
Расписание, печатная форма и PDF полностью поддерживают такие занятия: если время не ровно час, над именем ученика показывается точное время.

## Длительность и временная сетка (версия 3)
У занятия есть длительность (30–120 мин). Неделя, печатная форма и PDF рисуются временной сеткой: начало блока — по минутам, высота — по длительности. Пересекающиеся занятия сохранить нельзя (в том числе в регулярной серии — такое повторение пропускается). В боте порядок: ученик → дата → время → длительность → разовое/регулярное. В мини-аппе: «Оплаты» — общая лента с фильтрами и кнопкой «График» (круговая диаграмма), карточка ученика открывается для просмотра, карандаш справа вверху включает редактирование имени и цены. Старая база `tutor.db` мигрирует сама (длительность существующих занятий — 60 мин).
