# Ученики в «ИИ-проверке»

Источник — база приложения, как в разделе «Ученики»: глобальный массив `S` (грузится из `/api/data`),
`act()` отдаёт активных (без `deleted`), аватар рисует `av(s)` (цвет `hue(id)` из `BRAND_COLORS`, инициалы `ini(name)`).

Макет берёт эти функции сам, если они есть на странице. В автономном файле используется демо-список `DEMO_STUDENTS`.
Кнопка «Новый» вызывает `studNew()` приложения.

Сохранение: `saveWork()` пока показывает уведомление. На сервере нет эндпоинта для закрепления проверки за учеником
(в `bot.py` есть только `/api/student/add|update|delete`). Нужен, например,
`POST /api/essay/save {student_id, exam, text, errors, criteria}`.
