# Голосовой виджет Вишенки в «ИИ-проверке» — что нужно на сервере

Макет показывает три сценария: исправить ошибку, поправить распознанный текст, любая генеративная задача.
Текущий бэкенд (`bot.py`, `assist.py`) умеет только часть:

- `/api/fragment` отвечает на любую задачу по фрагменту (перепиши, найди аргументы…), но ответ уходит
  только в чат с ботом текстом. Изменить ошибку или распознанный текст в приложении он не может.
- `fragment_meta()` принимает фрагмент только из «Материалов»: `cat` из `MATERIALS`, `n` 1…`MAT_VARIANTS`,
  `part` из `FRAG_PARTS`. Фрагмент из сочинения ученика получит 400.
- `/api/voice` + `/api/voice_confirm` выполняют действия из фиксированного набора кабинета (расписание,
  ученики, оплаты) через `assist.execute()`.

Нужно добавить:
1. Контекст `essay`: `{kind:"essay", exam:"ege|oge", work_id, error_id?, page, fragment}` (в `voiceCtx()` и в запрос).
2. Действия `fix_error` и `edit_ocr` с параметрами `{error_id, replacement}`: ответ `stage:"confirm"`,
   применение через `/api/voice_confirm`, на клиенте — обновление текста и карточки ошибки.
3. Для остальных задач — тот же путь, что у `/api/fragment` (ответ в чат с ботом), но с валидацией под `essay`.
