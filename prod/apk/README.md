# APK (PROD) — Android-приложение «Надежда»

WebView-обёртка того же кабинета, что и мини-апп. Отличия этой (prod) сборки:

- подсказка по умолчанию — рабочий адрес `https://tutor-bot-cn4a.onrender.com/`
  (адрес можно сменить в приложении: долгое нажатие → «Сменить адрес сервера»);
- имя приложения — «Надежда», `versionName` — `1.0`;
- готовый `kabinet-repetitora.apk` лежит в этой папке.

## Сборка

Нужны JDK 17+ и Android SDK (build-tools 34.0.0, platform android-34).
Тулчейн ищется рядом с этой папкой: `../jdk` и `../android-sdk`.
Другое расположение:

```bash
export ANDROID_BUILD_ROOT=/путь/к/каталогу   # внутри — jdk/ и android-sdk/
sh build.sh                                   # на выходе: kabinet-repetitora.apk
```

Подпись: `build.sh` создаёт локальный ключ `build/ks.jks` (пароль `tutorpass`)
— это debug-подпись для установки «из рук». Для публикации в Google Play
нужен свой release-ключ: замените шаг `keystore`/`apksigner` на свой.

⚠️ Перед выпуском прод-сборки убедитесь, что изменения перенесены из
`../../dev/apk/` (и наоборот — dev-адрес не попал в прод).

Тестовая версия приложения — в `../../dev/apk/`.
