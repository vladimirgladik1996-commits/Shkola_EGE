Как пользоваться каталогом

Перед вами 36 сочинений к заданию 27 ЕГЭ-2027 по русскому языку — по одному на каждый вариант сборника Р. А. Дощинского. Каждый вариант оформлен единообразно: исходный текст, официальная формулировка задания 27, готовое сочинение и таблица проверки по критериям ФИПИ (К1–К10, максимум — 22 балла) с объяснением, почему работа получает высший балл.

Важно! Об изменениях ЕГЭ-2027

По официальному плану изменений КИМ ЕГЭ-2027 (ФИПИ) в работе по русскому языку изменений нет: структура задания 27 и критерии оценивания (К1–К10, 22 балла) остаются прежними. Готовьтесь по материалам этого каталога смело.

Жёсткое правило объёма

Каждое сочинение каталога содержит строго больше 150, но меньше 300 слов (151–299); точное число слов указано после каждого сочинения. Работа объёмом менее 150 слов на экзамене не оценивается.

Методика работы с литературным аргументом

Аргумент строится по схеме: тезис → цитата-опора → контекст → микровывод. В таблице критериев (строка К3) для каждого варианта показано, почему выбранное произведение подходит к проблеме текста.

Структура идеального сочинения задания 27:

  • формулировка проблемы (в форме вопроса или утверждения);
  • комментарий: два примера-иллюстрации из текста + пояснения + смысловая связь между ними;
  • позиция автора;
  • своё отношение к позиции автора («согласен / не согласен, потому что…»);
  • аргумент из литературы, жизни или знаний;
  • вывод.

Помните: для аргументации нельзя обращаться к комиксам, аниме, манге, фанфикам, графическим романам и компьютерным играм — такие аргументы не засчитываются.
