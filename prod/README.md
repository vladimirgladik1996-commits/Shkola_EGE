# PROD — рабочая версия

Живые ученики, занятия и платежи. Состав:

- `bot-mini-app/` — Telegram-бот + мини-апп (деплой и настройки: `bot-mini-app/DEPLOY.md`)
- `apk/` — Android-приложение «Надежда» (сборка: `apk/README.md`, готовый APK лежит рядом)

Особенности prod:

- **рабочий бот Telegram** и **рабочая база** `bot-mini-app/data/tutor.db` —
  нужны регулярные бэкапы (их делает `bot-mini-app/deploy.sh`, 14 последних копий);
- `APP_ENV=prod` — без пометок в интерфейсе;
- анти-сон включён (`KEEPALIVE_SEC=180`), `LOG_LEVEL=INFO`;
- секреты (`BOT_TOKEN`, `AUTH_*`) — только в `.env` на сервере / в панели Render,
  в репозиторий не попадают.

Правки сюда переносятся из `../dev/` после проверки — см. README в корне.
